# Agent Skills 智能体技能

一套个人使用的智能体技能集。

## 全局安装全部

```bash
npx skills add jerryshell/skills -y -g
```

## 个别选装

- **bro** - 用通俗易懂的人话重述上一条消息，去掉所有术语。

  ```bash
  npx skills add jerryshell/skills/bro
  ```

- **cleancode** - 优化重构代码。

  ```bash
  npx skills add jerryshell/skills/cleancode
  ```

- **docstyle** - 按统一规范撰写、改写和审阅中文技术文档、产品文案与界面文案。

  ```bash
  npx skills add jerryshell/skills/docstyle
  ```

- **grillme** - 对一个计划或设计进行持续不断的深入询问，直到决策树的每一个分支都得到明确解答。

  ```bash
  npx skills add jerryshell/skills/grillme
  ```

- **improve** - 以资深顾问身份审视代码库，生成优先级排序的实施计划；严格只读，不修改任何源代码。

  ```bash
  npx skills add jerryshell/skills/improve
  ```

- **updatedoc** - 以代码为事实更新文档。

  ```bash
  npx skills add jerryshell/skills/updatedoc
  ```

## skills 更新

项目级更新

```bash
npx skills update
```

全局更新

```bash
npx skills update -g
```
